# Plugin Development Phases – Lektorat Mac Booking

## Phase 1 – Core Form (Week 1–2)
- Build shortcode `[lm_booking_form]`.
- Create form UI with service selection, price display, customer details.
- Submit → store request as CPT + send emails.
- Basic responsive design.

## Phase 2 – Admin Essentials (Week 3)
- Settings page: manage services/prices as JSON.
- Email templates editable in admin.
- Admin booking list with customer name & total.
- Basic filters/search.

## Phase 3 – QA & Hardening (Week 4)
- Validation of all inputs (server-side).
- i18n and accessibility pass.
- Email deliverability tests with SMTP.
- Documentation handover (admin guide, logic, templates).
- Deploy to production.

*Optional Phase 2+ Features:* file uploads, extras, word count, surcharges, analytics.
