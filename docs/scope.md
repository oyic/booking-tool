# Project Scope – Lektorat Mac Booking

## Phase 1 (Confirmed Simplified Scope)
- Frontend booking request form (service selection → price → customer details → submit).
- Emails: client (summary), admin (detailed).
- Store requests in WordPress (CPT `lm_booking`).
- Mobile-first, responsive design with light animations.

## Phase 2 (Optional Enhancements)
- Word count → norm pages calculation.
- Delivery options with surcharges (+15%, +50%) and +24h buffer.
- Extra services with fixed prices (€20, €30, €40, €50).
- Mandatory file uploads (editable formats, secure storage).
- Admin panel for packages, extras, fields, and email templates.
- FAQ management in backend.
- Analytics integration (orders, conversions, drop-offs).
- KPI dashboard in admin.
- Automated backups and performance tuning.

## Phase 3 (Future)
- Multi-language support.
- Notifications beyond email (SMS, push).
- Extended UX animations (GSAP polish).
